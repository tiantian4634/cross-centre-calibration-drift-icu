## 0. 总体评价

图表整体质量高于普通初稿，具体优点：

- 每张图承载一个明确论点，图序（流程 → 漂移存在 → 判别/校准解离 → 病例组合 → 规模/临床影响 → 朴素重校准失败 → EB 收缩成功 → 跨库迁移）构成完整论证链；
- 配色克制、风格统一，PDF 矢量版与 PNG 同步输出，符合投稿要求；
- `图注_legend.md` 中已有「方法学红线入注」的自觉（残余变异不归因医疗质量、MIMIC 非外部验证等），这是重要加分项。

但当前版本存在三类会被审稿人直接指出的问题：

1. **图与正文/表格的数值不一致**（0.1 个百分点级的舍入冲突）；
2. **部分图内措辞与正文精心设计的「诚实表述」相互矛盾**（"range" vs "P10–P90"、"External" vs "transfer"）；
3. **多处文字碰撞、低对比度、坐标轴不一致**，达不到出版质量。

以下按优先级 A（硬伤）/ B（图面）/ C（合规）分级列出，每条给出**问题 → 审稿风险 → 修改建议（含代码位置）**。

## A. 硬伤——必须修改

### A1 ⚠️ 图、表、正文数值不一致（舍入冲突）

| 位置 | 图中值 | 正文/表格值 | 根因 |
|---|---|---|---|
| Fig. 2 SOFA 面板 | *I*² = **75.3%** | Table 1 / Results：**75.4%** | 源值 75.35，Python `:.1f` 舍入到 75.3 |
| Fig. 2 SAPS-II 面板 | *I*² = **70.3%** | Table 1 / Results：**70.4%** | 源值 70.35 |
| SuppFig. S1 M1 柱 | *I*² = **75.3%** | Results：**75.4%** | 同上 |
| Fig. 5 左面板大中心 | *I*² = **83.8%** | Results / 图注：**83.9%** | 源值 83.85 |
| Fig. 4 右面板 m=25 | 15.3% | Abstract / Fig. 6 段落：15.5% | 见 A2（不同重抽样运行，非舍入） |

**审稿风险**：本文核心卖点是「预注册 + 诚实报告」，审稿人会逐项核对 Table 1 ↔ 图 ↔ 正文；0.1 个百分点的冲突足以引发「作者是否认真核对过所有数字」的怀疑，并连带动摇对预注册声明的信任。

**修改建议**：
1. 全库统一舍入函数（对 x.x5 一律进位），替换所有绘图脚本中的 `:.1f` 直接格式化。可新增公共工具函数：

```python
# 加入共享模块（如 figures_common.py），所有 figures_*.py 引用
from decimal import Decimal, ROUND_HALF_UP

def r1(x) -> str:
    """一位小数，x.x5 一律进位——与正文/Table 1 的舍入规则一致。"""
    return str(Decimal(f"{float(x):.6f}").quantize(Decimal("0.1"), rounding=ROUND_HALF_UP))
```

2. 替换点（已定位）：
   - `figures_drift.py:47`（Fig. 2 面板内 *I*² 标注）
   - `figures_drift.py:102`（SuppFig. S1 柱顶 *I*² 标注）
   - `figures_batch2.py:66`（Fig. 5 左面板柱顶 *I*² 标注）
3. 重出图后，在 `质检_装配后.py` 中增加一条硬性检查：**图脚本输出的 I²/τ²/成功率字符串必须与 `结果汇总_v1.md` 中的对应字符串逐字相同**（可复用现有 `回归检查_图注硬编码.py` 的机制）。

### A2 ⚠️ 15.3% 与 15.5% 双来源未说明

Fig. 4（100 次重复）给出 m=25 时朴素重校准成功率 **15.3%**；Fig. 6 与摘要（200 次重复、配对设计）给出 **15.5%**。两者来自不同的重抽样运行，数值均正确，但正文无一句话交代差异来源。

**审稿风险**：审稿人核对 Fig. 4 → Fig. 6 时必然发现，会问「到底哪个是 15.3？」；若不解释，可能被解读为选择性报告。

**修改建议**：在 Fig. 6 段落末尾或 Fig. 6 图注加一句（英文）：

> *Naive-recalibration success rates differ marginally between Figure 4 (100 resamples per cell) and Figure 6 (200 resamples, paired design), reflecting independent resampling draws; comparisons of interest are within, not between, figures.*

### A3 ⚠️ Fig. 3 标注框把 P10–P90 说成 "range"

`figures_drift.py:79` 写死：

```
AUC: 0.649 – 0.812  (range 0.16)
O/E: 0.69 – 1.54      (range 2.2-fold)
```

但按 Table 1，0.649–0.812 与 0.69–1.54 均为 **10th–90th 百分位，不是极差（min–max）**。正文与 Table 1 图注反复强调「ranges given are 10th and 90th percentiles, not confidence intervals」，图内却标 "range"——**图文自相矛盾，且恰好违背本稿自设的诚实表述红线**。

**修改建议**：改为

```
AUC: 0.649 – 0.812  (P10–P90 width 0.163)
O/E: 0.69 – 1.54      (P10–P90 ratio 2.2-fold)
```

同一问题也存在于 **Fig. 5 右面板** 的区间标注（`13–31% / 15–52% / 0–70% / 0–100%`），建议在数字前统一加 `P10–P90` 前缀，或在面板 y 轴标签中注明（如 `Observed mortality among those flagged, % (median ▪; P10–P90 bar)`）。

### A4 ⚠️ Fig. 7 面板标题 "External (MIMIC-IV)" 与正文声明冲突

Results 末尾以加粗声明：「*This analysis tests whether the shrinkage parameters transfer across databases. **It is not multicentre external validation of the strategy***」；`图注_legend.md` 亦有「两者不得混称」的红线。但 **Fig. 7 右面板标题直接写 "External (MIMIC-IV)"**——图上打了自己声明的耳光，这是审稿人最容易引用的矛盾点。

**修改建议**（`figures_mimic_external.py`）：
- 左面板标题：`Internal cross-fitting (103 eICU centres)`
- 右面板标题：`Transfer to MIMIC-IV (treated as a single new centre)`
- 若标题过长，可缩短为 `MIMIC-IV as one new centre (parameters fixed from eICU)`，细节留给图注。

### A5 ⚠️ SuppFig. S1 的 M3 柱与 M1/M2 不是同一分析集

M3 因 Charlson 合并症缺失使用 complete-case set（**n = 27,236、97 家中心**），M1/M2 为 30,796、103 家。图上三根柱并排、无任何标注，视觉上暗示「同一队列逐级调整」。

**审稿风险**：I² 从 75.2% 降到 70.1% 的一部分可能来自分析集变化而非协变量调整；方法学审稿人几乎必问。

**修改建议**：
1. M3 柱 x 轴标签下直接加注 `n = 27,236; 97 centres`（`figures_drift.py` SuppFig S1 段落），图注同步写明 complete-case set；
2. **（强烈建议，防御力最强）** 增加一根参照柱：`M1 (restricted to M3 complete-case set)`，证明 I² 下降不是分析集变化造成的。此为「改现有图内容」，不新增 display item，不违反 8 项上限。若该参照柱的 I² 与 75.3% 几乎相同，则「实测病例组合解释不了漂移」这一最易受攻击的论点将几乎不可反驳。

### A6 ⚠️ 学习曲线（Fig. 4/6/7）随 m 变化的中心构成未在图上体现

m 增大时纳入中心数 103 → 59 → 13（n ≥ 2m 要求），正文有交代，图上没有。由此产生一个**图面误导**：Fig. 4/6 左面板 S0（不重校准）的中位残余 |a| 随 m「下降」（0.31 → ~0.20），这不是策略效果，而是**小中心被逐步剔除的中心构成效应**。读者会将其误读为「不重校准也会随 m 变好」。

**修改建议**：
1. x 轴刻度下加一行小字：`k = 103 / 103 / 103 / 59 / 13`（Fig. 4、6、7 左面板）；
2. 图注补一句：

> *The set of contributing centres shrinks as m increases (k = 103, 103, 103, 59, 13); changes across m therefore reflect both local sample size and centre composition. The S0 line is the within-m reference, not a learning effect.*

### C2 Sci Rep 投稿格式核对

| 项 | 现状 | 行动 |
|---|---|---|
| 文件格式 | PNG + PDF 双格式 ✔ | 核对该刊对插图格式的最新要求（通常接受 TIFF / EPS / PDF；**PNG 不一定被接受**），投稿时以 PDF/EPS 为矢量主文件 |
