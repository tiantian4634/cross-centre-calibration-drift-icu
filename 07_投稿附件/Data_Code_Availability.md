# Data and Code Availability Statements

Manuscript: *Discrimination transports, calibration does not: cross-centre and temporal drift in acute
severity scoring across 187 ICUs, and the sample size needed to recalibrate*

---

## 1. Data availability

### Primary data
This study is a **retrospective secondary analysis of two publicly available, de-identified critical care
databases**. No new data were collected and no identifiable human data were generated by this work.

| Database | Version | Access | Role in this study |
|---|---|---|---|
| **eICU Collaborative Research Database** | v2.0 | PhysioNet, credentialed access (training + attestation of data use agreement required) | Estimation cohort — 208 hospitals, 200,859 unit stays screened; 30,796 patients from 187 hospitals analysed; 103 centres eligible for centre-level analyses |
| **MIMIC-IV** | v3.1 | PhysioNet, credentialed access (Completed CITI "Data or Specimens Only" training and DUA required) | External application — single centre (Beth Israel Deaconess Medical Center), 8,579 patients |

Access to both databases is free to qualified investigators but requires an application and a data use
agreement; typical turnaround is several weeks. Neither database can be redistributed.

### What we do share
1. **Complete extraction code.** Scripts that reproduce the cohorts from the raw PhysioNet tables, including
   every inclusion and exclusion step and the exact step-wise counts shown in Figure 1. Anyone with
   credentialed access can regenerate the analysis cohort and reproduce every number in the manuscript.
2. **A centre-level summary table with no patient-level data** (`hospital_level_三评分.csv`): one row per
   eligible centre (n, deaths, observed and expected event rates, observed-to-expected ratio, calibration
   offset and its standard error, per-centre AUC and calibration slope) for each of the three severity
   scores. **This table contains no patient identifiers, no dates and no free text**, and is deposited at
   the repository DOI below. It is the minimal object required to reproduce Figures 3 and 4.
3. **All derived result files** (per-centre tables, bootstrap and resampling outputs, heterogeneity
   estimates under all four estimation frameworks, sensitivity analyses).

### What we do not share
Patient-level rows from either database are **not** redistributed, consistent with the terms of both data
use agreements.

### Compliance note
The public code repository ships with a `.gitignore` that **excludes every patient-level artefact**
(`eicu_hospital_context.csv`, `hospital_id_map.csv`, and any `cohort_*.csv` or `02_数据集/` content), so that
the released repository cannot inadvertently redistribute PhysioNet-derived patient records or any key that
would link back to them. Two large centre-level resampling files (`shrinkage_raw.csv`, 16 MB;
`learning_curve_raw.csv`, 2.8 MB) are excluded from version control and offered instead as repository
attachments; they contain centre identifiers and aggregate statistics only.

### Cohort construction
`cohort/README.md` documents every inclusion and exclusion criterion in execution order for both databases,
and `cohort/` contains the **step-wise count reports emitted by the extraction stage** — these, rather than
a later reconstruction, are the source of every number in Figure 1. The extraction itself needs credentialed
PhysioNet access and is therefore not re-run by the repository.

### Data quality and provenance
All database access during the analysis was **read-only**. Counts reported in Figure 1 were taken from the
extraction stage's own count reports rather than re-derived, so that the published flow diagram reflects the
actual pipeline rather than a reconstruction.

All analysis and figure-generation code is openly available.

**Repository:** https://github.com/tiantian4634/cross-centre-calibration-drift-icu

### Pipeline, in execution order

| Stage | Script | Produces |
|---|---|---|
| 0 | `extract_hospital_context.py` | Cached centre-level fields (`eicu_hospital_context.csv`) so that later stages need no database access |
| 1 | `roadB_probe.py` | Feasibility probe: I² and centre counts across thresholds |
| 2 | `analysis_drift.py` | Analyses A–D: three-score drift, calibration slopes, case-mix ladder, MIMIC positioning |
| 3 | `analysis_learning_curve.py` | Analysis E: local recalibration learning curve |
| 4 | `analysis_batch2.py` | Analyses F–H: split-half temporal stability, size stratification, clinical impact |
| 5 | `analysis_shrinkage.py` | Analysis I: empirical-Bayes shrinkage versus naive recalibration |
| 6 | `analysis_mimic_external.py` | Analysis J: transfer of shrinkage parameters to MIMIC-IV |
| 7 | `analysis_tau2_framework.py` | Analysis K: τ² under DerSimonian-Laird / Paule-Mandel / REML / multilevel logistic |
| 8 | `analysis_tau2_sensitivity.py` | Sensitivity of the main conclusion to the choice of τ² |
| — | `diagnose_multilevel.py`, `verify_vcp_parameterization.py` | Diagnostics used to settle a parameterisation question (see manuscript) |
| — | `figure1_flowchart.py`, `figures_drift.py`, `figures_batch2.py`, `figures_shrinkage.py`, `figures_mimic_external.py` | Figures 1 and 3–11 |

Stages 1–8 read only local CSV/JSON artefacts produced by stages 0–2, so a reader with the repository can
rerun the statistical work without database credentials. Only stage 0 requires PhysioNet access.

### Determinism
- Global seed **20261019**; resampling uses explicitly seeded `numpy.random.Generator` instances, so every
  resampling-based result is bit-reproducible.
- Plan files are written **idempotently** (never overwritten once present), preserving the timestamps that
  evidence the analyses were specified before they were run.

### Environment
Python 3.14 with `pandas`, `numpy`, `scikit-learn`, `scipy`, `statsmodels` (0.14.6), `matplotlib`, and
`duckdb` (for read-only PhysioNet queries). Exact versions are pinned in `requirements.txt` in the repository.
